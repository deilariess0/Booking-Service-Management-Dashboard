# Clean Genie Cleaning Co - Admin Dashboard

**Clean Genie Cleaning Co** is a full-stack booking service management platform. This repository contains the **Admin Dashboard**, a powerful, role-based web application designed to efficiently manage the day-to-day operations of the cleaning business.

## ✨ Features

*   **Interactive Dashboard:** Real-time overview of total bookings, collected revenue, pending payments, and actionable insights.
*   **Visual Analytics:** Dynamic charts and graphs to track booking trends, revenue overview, and top-performing services.
*   **Bookings Management:** Complete control over the booking lifecycle, allowing admins to filter, search, confirm, complete, or cancel customer requests.
*   **Role-Based Admin Management:** Securely manage team access by adding admins and assigning specific roles (Super Admin/Admin).
*   **Comprehensive Reports:** Detailed reporting module with the ability to export data to CSV, including breakdowns of revenue and payment statuses.

## 🛠️ Tech Stack

*   **Frontend Framework:** React JS
*   **Styling:** Tailwind CSS
*   **Language:** JavaScript
*   **Deployment:** Vercel
